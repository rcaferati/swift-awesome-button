# ``SwiftAwesomeButton``

Build responsive, accessible 3D buttons for SwiftUI and UIKit from one package-owned interaction contract.

## Overview

Use ``AwesomeButton`` for direct styling, ``ThemedButton`` for the built-in theme vocabulary, or the UIKit controls when integrating with an existing view-controller hierarchy. Every surface shares callback ordering, progress ownership, cancellation, accessibility, validation, and Reduced Motion semantics.
