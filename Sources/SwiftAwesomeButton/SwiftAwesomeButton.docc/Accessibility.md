# Accessibility

Text labels provide their own activation label. Custom content should set `accessibilityLabel`; optional hints and long-press labels complete the control's meaning.

SwiftUI and UIKit surfaces expose native activation and long-press accessibility actions, disabled and busy state, a minimum 44-point target, Dynamic Type-aware geometry, and physical-corner RTL behavior. Verify product-specific wording with VoiceOver, Switch Control, Full Keyboard Access, large text, and RTL layouts.
